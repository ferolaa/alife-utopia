# Phase 3 prerequisites — no implementation or experiment started

The existing developmental mechanism sets impairment at independence to the capped
fraction of dependency spent unattended. It subsequently attenuates the adult's own-pup
signals; network weights are unchanged. Impairment is permanent in the current code:
low-density transfer cannot repair it. A result showing persistence would therefore
demonstrate consequences of the supplied rule, not discovery of lasting biological or
learned neural damage. A claim of physiological recovery requires a new, explicitly
approved model assumption; do not silently introduce one.

Before execution:

1. Approve and preserve Phases 1/2 on GitHub or an independently verified backup.
   Keep original checkpoints read-only and use a new Phase 3 result directory.
2. Prespecify early-care exposure, transfer time, endpoints and analysis. Include the
   developmental-damage flag OFF/ON and identical low-density transfer conditions.
   Keep policy, caregiver, resources and age/energy controls explicit and matched.
3. Address survivor selection. Severe disruption killed almost all pups in Phase 2.
   Conditioning only on survivors can create a biased apparent impairment comparison.
   Report assigned-cohort survival/recruitment alongside survivor-only behavior. Any
   exposure-duration choice must be justified before final outcomes, not tuned to collapse.
4. Define whether transfer normalizes energy. Preserve age, neglect history and identity;
   release/reassign nests and parent links correctly. Prevent accidental resetting of
   impairment. Equal energy isolates the cue-impairment pathway but removes a nutritional
   carryover pathway; state that scientific choice.
5. Independence occurs at age 60, but reproductive maturity is 120. Distinguish immediate
   adult movement/foraging from later parenting. A supplied-pup assessment at matched
   mature age can isolate care ability from breeding opportunities, but needs approval.
6. Verify impairment is settled exactly once, retained through transfer, and limited to
   intended inputs; tests must establish flag-OFF controls, unchanged weights, matched
   observations apart from the intended impairment, and correct mortality accounting.
7. Use independent training pairs as inference units. Prespecify how dependent siblings,
   shared worlds, non-survivors and incomplete follow-up enter denominators.

Frozen shared RL policies assign the same trained network to every adult. This is not
individual neurodevelopment, genetic inheritance or relearning after recovery. The
current model has no memory-based rehabilitation mechanism. Future interpretations
must distinguish persistent programmed cue attenuation from behavior in a less demanding
environment. Intrusion and other breakdown mechanisms should remain separate hypotheses.

Phase 3 can be designed safely with isolated outputs and frozen inputs, but it should
not start until preservation is approved and these scientific choices are settled.
